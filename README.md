## How it works / 运作方式

- **Source**: GitHub Trending (daily, with a monthly backfill), filtered for AI agent skills and AI-related repositories by name, description and topics.
- **Daily update**: new trending repos are added the day they chart; star counts of every tracked repo are refreshed daily.
- **Summaries**: each repo gets a short bilingual summary (English + 中文) written from its README / homepage.
- **Data**: everything is in [`data/repos.json`](data/repos.json) — machine-readable, feel free to build on it.

数据源为 GitHub 趋势榜（日榜 + 月榜回填），按仓库名、简介与 topics 筛选 skills 与 AI 相关仓库，每日增量更新。
